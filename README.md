# 🛡️ SafeTour
### Smart AI-Based Passenger Safety Management System using Geo-Fencing & Blockchain Digital ID

> Your Safety, Our Journey

SafeTour is an intelligent tourist safety platform designed to enhance traveler security through the integration of **Artificial Intelligence**, **Geo-Fencing**, **Blockchain-based Digital Identity**, and **Real-Time Emergency Response Systems**.

The system provides proactive threat detection, secure digital identity verification, location-aware safety alerts, and rapid incident response to ensure a safer travel experience for domestic and international tourists.

Developed as a solution for **Smart India Hackathon 2025 (SIH25002)** under the themes of **Security & Surveillance** and **Tourism Safety**.

---

## 📌 Problem Statement

Tourists frequently encounter challenges such as:

- Theft and harassment
- Getting lost in unfamiliar locations
- Delayed emergency assistance
- Identity verification issues
- Language and communication barriers
- Lack of centralized safety infrastructure

Existing solutions address these issues independently but fail to provide an integrated and intelligent safety ecosystem.

SafeTour aims to bridge this gap through a unified platform combining AI, Blockchain, and Geo-Fencing technologies.

## 📍 Geo-Fencing Safety Zones

SafeTour creates virtual geographic boundaries around tourist destinations.

### Capabilities

- Safe zone monitoring
- Restricted area detection
- Location-based alerts
- Route safety recommendations
- Emergency tracking

When a tourist enters a potentially dangerous area, automatic notifications can be sent to:

- Local authorities
- Emergency services
- Registered emergency contacts

## 🔐 Blockchain-Based Digital Identity

Each tourist receives a secure digital identity stored on a blockchain network.

### Features

- Tamper-proof records
- Secure verification
- Fraud prevention
- Emergency identification
- Decentralized authentication

### Advantages

- Eliminates forged identity issues
- Provides trusted verification
- Preserves user privacy
- Ensures immutable records

# 🔄 Workflow

## Tourist Registration

1. User creates account
2. Identity verification completed
3. Blockchain Digital ID generated
4. Profile stored securely

## Location Monitoring

1. GPS location tracked
2. Geo-fence engine evaluates position
3. Risk level calculated
4. Alerts generated if necessary

## Emergency Handling

1. Tourist presses SOS button
2. Incident logged
3. Live location shared
4. Authorities notified
5. Response initiated
